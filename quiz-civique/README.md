# Quiz Civique - Naturalisation

Application de quiz pour préparer l'examen civique de naturalisation française.

## Format du Quiz

Le quiz suit le format officiel de l'examen civique avec **40 questions** réparties par thème :

| Thème | Nombre de questions |
|-------|---------------------|
| Principes et valeurs de la République | 11 |
| Système institutionnel et politique | 6 |
| Droits et devoirs | 11 |
| Histoire, géographie et culture | 8 |
| Vivre dans la société française | 4 |
| **Total** | **40** |

Pour réussir, il faut obtenir au minimum **32 bonnes réponses (80%)**.

## Fonctionnalités

- **263 questions** issues de la liste officielle
- **Format officiel** : répartition des questions par thème identique à l'examen
- **Suivi de progression** : statistiques de vos quiz (nombre de quiz, moyenne, meilleur score)
- **Favoris** : possibilité de marquer des questions pour les revoir plus tard
- **PWA** : application installable sur mobile et utilisable hors-ligne

## Installation

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - Lancer le serveur de développement
- `npm run build` - Compiler pour la production
- `npm run preview` - Prévisualiser la version de production
